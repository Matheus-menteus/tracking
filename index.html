💡 Por que o Robô do GitHub é o método mais garantido para puxar Quinta-feira e todos os dias passados?
Quando você abre o site pelo navegador, o Chrome/Safari bloqueia chamadas diretas para garmin.com por segurança de domínio (CORS). Já o GitHub Actions roda no servidor do próprio GitHub (fora do navegador): ele entra no Garmin Connect, puxa Segunda, Terça, Quarta, Quinta, Sexta, Sábado e Domingo retroativamente, grava tudo no seu memoria.json e marca seus hábitos!
Já configurou o arquivo no seu repositório?
Basta ter o arquivo sync_garmin.py e .github/workflows/garmin_sync.yml no seu repositório (e colocar GARMIN_EMAIL / GARMIN_PASSWORD ou GARMIN_API_KEY em Settings → Secrets → Actions). Sempre que ele rodar, todos os dias anteriores da semana aparecerão preenchidos aqui automaticamente!
